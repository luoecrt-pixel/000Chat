# Astra v4.15.1

## Build fixes
- Fixed `List`/`MutableList` mismatch in resumed-response finalization.
- Added a `Long` overload for token formatting so usage totals compile correctly.
- Added static verification checks for the reasoning-summary path.

## Reasoning summaries
- Uses the existing `reasoning.summary` setting (`auto` / `concise` / `detailed` / disabled).
- Parses final `reasoning` output items and their `summary_text` parts.
- Handles live `response.reasoning_summary_text.delta` events during streaming.
- Shows a collapsed `🧠 Показать ход рассуждений` panel.
- The panel exposes the API-provided reasoning summary, not private raw chain-of-thought.
- The summary is persisted with assistant messages and restored with chat history.

## CI
- The supplied failed run showed the repository was still executing an older workflow (`checkout@v4`, `setup-android@v3`, `setup-gradle@v4`).
- The source archive contains the canonical updated workflow at `.github/workflows/build.yml`, but GitHub will not use that file until the repository's actual workflow file is replaced.
