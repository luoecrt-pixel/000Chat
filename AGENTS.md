# Инструкции для агентов 000Chat

Этот репозиторий развивается для прямых API OpenAI и DeepSeek. Оставшийся исполняемый OpenRouter удаляется по задаче #34 в [AGENT_TASKS.md](AGENT_TASKS.md); OpenRouter/Claude и его дальнейший план относятся к [форку `000Chat-OR`](https://github.com/luoecrt-pixel/000Chat-OR). Общие компоненты с OR-именами, используемые DeepSeek, и совместимость старой истории сохраняются.

Прочти [NEXT_AGENT_HANDOFF.md](NEXT_AGENT_HANDOFF.md) (необходимые постоянные правила) и [AGENT_TASKS.md](AGENT_TASKS.md) (единственный актуальный план и критерии). [PROJECT_HISTORY.md](PROJECT_HISTORY.md) — только для разбора неочевидных прежних решений, не обязательный журнал для каждого нового агента.

Последнее поручение владельца приоритетнее устаревших заметок. Перед изменением сверь действительные main/PR/тесты/CI; не применяй старые ZIP-пакеты или patch-инструкции к нынешнему коду.
