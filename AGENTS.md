# Работа с репозиторием

Начать с [NEXT_AGENT_HANDOFF.md](NEXT_AGENT_HANDOFF.md): текущий baseline, ближайшая работа, ограничения и CI. Подробные новые задачи ведутся в [существующем аудите](docs/audits/2026-10-12-openai-followup.md).

Инструкции владельца в разговоре приоритетны. Перед изменением проверить main, открытые PR и локальный diff; не переписывать чужую работу. Старый partial ZIP уже применён.

Сохранять Stop/request-aware CAS, полную историю/originals, signed replay/fingerprint v1, manual effort, 1h cache и 5h/5M границы. Не ослаблять TLS/JPEG/SHA/renderer isolation. Не выполнять платные API и не работать с телефоном без отдельного поручения.

Этап ограничен 40 минутами; результаты/remaining записывать кратко в handoff/PR. Не создавать архивы и дублирующие отчёты: неактуальное удалять, уникальное действующее важное сохранять в handoff. Текущий PR уборки merge делает владелец.
