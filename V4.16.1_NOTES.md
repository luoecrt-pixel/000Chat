# Astra v4.16.1

## CI fixes
- Added `import okio.buffer` for Okio 3.x.
- Fixed nested Kotlin `it` shadowing (`Bitmap` vs `View`).
- Usage/cost token accounting uses `Long` end-to-end.

## Attachment UX fixes
- Immediate attachment cards + progress from preparation through upload.
- Image thumbnails now work for generic file-picker image selection too.
- Text/JSON/CSV/code preview in attachment cards.
- PDF first-page preview.
- Sent user-file local paths are persisted back into SQLite after remote download.
- Fixed an infinite loop in the old user-file path update code.
- `Скачать и открыть` immediately previews downloaded files when supported.
- ZIP is never expanded just by selecting it; expansion happens only after Send.

## Generated files
- Prefer valid local cache even when old metadata is stale/EXPIRED.
- Legacy generated-file cache lookup by filename can repair older on-device files.
- Generated assets remain directly below the assistant message that created them.

## Reliability
- Added DB index on `(chat_id, request_id)`.
- Capped full PDF preview bitmap dimensions.
- Removed duplicate `Открыть` action in local Astra file library.

## Verification
`tools/verify_v4_16_1.py` = PASS.
