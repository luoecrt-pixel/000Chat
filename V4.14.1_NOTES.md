# Astra v4.14.1

## Build fixes
- Re-enabled Android `BuildConfig` generation for AGP 8+ (`buildFeatures.buildConfig = true`).
- Fixed SQLite transaction lambda receiver errors in `ChatDatabase`.
- Fixed DB migration path: the old duplicate `request_id` migration no longer runs; schema is now version 7 with `file_sizes` and `generated_images`.
- Canonical GitHub Actions workflow is `.github/workflows/build.yml`.

## Reliability / API
- Do not combine `configuration_update` with automatic compaction; compaction is skipped on the request that changes reasoning configuration.
- Persist the user + assistant messages before rendering annotations so file state updates always have a DB row.
- Track uploaded file sizes and enforce the 50 MB total input-file budget when sizes are known.
- Support both `container_file_citation` and `file_citation`. Container files auto-download; File Search citations show a deliberate `Скачать` action.

## UX
- Generated images from `image_generation_call.result` are saved locally, rendered with sampled previews, and exposed as Open / Save / Share.
- Chat picker now uses lightweight summaries instead of loading every message for every chat.
