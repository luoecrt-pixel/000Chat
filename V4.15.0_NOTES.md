# Astra v4.15.0 notes

This release builds on v4.14.1 and focuses on the requested usability/reliability features:

- Tool activity UI: live running/completed/failed status for Web Search, File Search, Code Interpreter, Image Generation and Computer Use when events are received.
- Local Astra file library: list generated/downloaded local files with Open/Save/Share/Delete.
- Background Responses: requests are created with background=true by default (configurable). Closing/restarting the Android Activity only closes the local stream; the server-side response continues and is automatically reconciled on next app start/switch back. Explicit Stop cancels the background response.
- Composer persistence: draft text, uploaded attachments and pending upload source URIs are restored per chat. ZIP selections must be picked again after restart.
- Usage/cost stats: today/7 days/all-time token totals and approximate Astra text-token cost, with reasoning breakdown.
- Preflight warning: a long existing chat history warns before sending because it can increase latency/cost.
- SQLite schema v10: durable active-response state plus estimated cost telemetry.
- v4.15.0 does not change the GitHub Actions workflow path; `.github/workflows/build.yml` remains canonical.
