# Astra v4.16.2

CI/packaging reliability patch on top of v4.16.1.

- Robustly locate a Gradle project either directly in the repository or inside a single source archive, including nested archive locations.
- Avoid failing with a misleading “no Gradle project root” message when the repository only contains the source archive outside the root.
- Run the matching verifier when it is present; keep build root independent from archive layout.
- Version bumped to 4.16.2 / versionCode 62.
- No user-facing API behavior was intentionally changed beyond CI/build robustness.
