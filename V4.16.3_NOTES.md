# Astra v4.16.3

Reliability/UX patch on top of v4.16.2.

- DB schema bumped to v14 with per-response `active_background_enabled`.
- Background recovery now honors the mode selected when the response started.
- Background worker and Activity polling reject stale `request_id` state.
- Background finalization persists the assistant message only through an atomic active-request check.
- Streaming/background updates preserve the user's scroll position when they are reading older history.
- New outgoing user messages still force the conversation to the latest item.
- VersionCode bumped to 63.
- CI verifier moved to `tools/verify_v4_16_3.py`.
